# Брифы и кабинет администратора

На сайте появились три отдельные формы, закрытый кабинет, приватное хранение ответов и фотографий, а также скачивание фотографий в ZIP-архиве.

## Ссылки для гостей

- Свадьба: `https://djalbirov.kz/brief.html?type=wedding`
- Юбилей: `https://djalbirov.kz/brief.html?type=anniversary`
- Корпоратив: `https://djalbirov.kz/brief.html?type=corporate`
- Кабинет администратора: `https://djalbirov.kz/admin.html`

В кабинете можно копировать ссылки, просматривать ответы, менять статус заявки, оставлять внутреннюю заметку и скачивать прикреплённые фотографии архивом. Фотографии и ответы хранятся в приватном Vercel Blob, URL файлов снаружи не открываются.

## Настройка пароля администратора

Для входа проекту нужны две переменные Vercel:

- `ADMIN_PASSWORD` — пароль входа в кабинет.
- `SESSION_SECRET` — секрет подписи сессий, минимум 32 символа.

Добавьте их в Project Settings → Environment Variables для Production, Preview и Development, затем создайте новый deployment. Не публикуйте значения в репозитории. Установленное приватное Blob-хранилище уже подключено к проекту.

## Ограничения фотографий

Можно прикрепить до 20 файлов в одном брифе, каждый размером до 10 МБ. Поддерживаются JPEG, PNG, WebP и HEIC/HEIF. Файлы проходят в приватное хранилище напрямую из браузера, не попадая в публичную часть сайта.
